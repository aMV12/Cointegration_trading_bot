# Cointegration Trading Bot

Проект с экспериментами по парному трейдингу и коинтеграционным стратегиям. В репозитории собраны ноутбук с исследованием идеи, скрипт для тестирования логики и CSV-файлы с историческими данными и результатами прогонов.

## Что делает проект

- проверяет коинтеграцию между двумя инструментами;
- строит спред и оценивает отклонения от среднего;
- использует исторические данные для тестирования парной стратегии;
- содержит заготовки для работы как с криптовалютами, так и с инструментами MOEX.

## Состав репозитория

- `Cointegration Test in python.ipynb` - исследовательский ноутбук с расчётом коинтеграции, спреда и базовой логики стратегии;
- `main_test.py` - основной Python-скрипт с функциями загрузки данных, расчёта метрик и тестирования стратегии;
- `*.csv` - исторические данные по отдельным тикерам и файлы с результатами сделок, ошибок и промежуточных расчётов.

## Особенности

- Проект носит исследовательский характер: основная логика собрана вокруг ноутбука и тестового скрипта.
- В коде есть места, рассчитанные на локальную конфигурацию и внешние API.
- CSV-файлы в репозитории используются как входные данные и как журналы результатов.

## Ограничения

- Для полноценного запуска может потребоваться донастройка зависимостей и конфигурации доступа к биржевым данным.
- Некоторые части кода ориентированы на локальную среду автора и не оформлены как готовое приложение.
